# Personal Portfolio Website

A modern and responsive personal portfolio website designed to showcase my skills, education, projects, and services as a Front-End Web Developer.

## Overview

This portfolio highlights my web development journey, technical skills, and selected projects through a clean user interface, responsive layouts, and interactive elements. It is designed to provide a consistent browsing experience across desktop, tablet, and mobile devices.

## Features

- Fully responsive design
- Modern and clean user interface
- About Me section
- Education and technical skills
- Projects showcase
- Services section
- Contact section
- Interactive elements using JavaScript
- Responsive layouts using CSS Grid and Flexbox

## Technologies

- **HTML5** — Semantic website structure
- **CSS3** — Styling, layouts, animations, and responsive design
- **JavaScript** — Interactive functionality
- **CSS Grid & Flexbox** — Flexible and responsive layouts
